Executor rule: re-run the grep before editing; any hit that is NONE of those four kinds (not a focus outline, ring stroke, spinner arc or drag border) becomes `var(--ink)` per the requester, and the SUMMARY lists it. Flag this decision in the SUMMARY so the requester can override.
2. **Most rendered 16px comes from `:root { font-size: 16px }`, not only from the 29 explicit declarations.** A computed sweep of the running app (1280x800, 8-row sample export) showed 16px on the skip link, the identity values, the section intro and note paragraphs, the provenance count, the unsupported-banner suffix, and the phone title, all of which inherit or declare it; 13.33px on the visually hidden file input and the phone back button (native controls with no font rule); and 28px on the Payments spend headline. 3. **Spend headline 28px becomes 26px (Display role, line-height 1.3).** 26px is the nearest declared role and it is smaller than today, so a long total cannot overflow where it did not before, and no second `max-width: 480px` rule is added (the review already counts nine phone rules as a defect).

The sticky region (inside the existing `min-width: 900px` block, with a `--list` background) kept both actions fully visible at every height measured. Below 900px the pane is not a scroll container, so sticky is not applied there.
5. **`src/lib/ui-copy.ts` is frozen and is not edited.** It holds one of the old greys, inside a doc comment only; the guards strip comments before scanning.
6. **No new e2e `test()`.** The e2e budget is at its ceiling (239 listed tests).
