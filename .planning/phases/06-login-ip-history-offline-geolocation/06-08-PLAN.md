## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker view to DOM | The view carries full canonical addresses so the reveal needs no round trip; the DOM must hold only what is displayed |
| user gesture to mask state | One button flips the only state; nothing else may change it or persist it |
