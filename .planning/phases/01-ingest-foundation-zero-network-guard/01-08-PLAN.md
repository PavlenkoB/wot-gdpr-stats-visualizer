<objective>
Close advisory finding **WR-01** against `src/lib/worker-client.svelte.ts`: an `onerror` while idle AND ready does not mark the worker broken; a later `submitFiles()` then calls `postMessage` on a dead worker, hangs on the busy floor (`MIN_PROCESSING_MS` timer never resolves because no reply will arrive), and never settles to a user-visible failure.

The fix is a one-line guard: every `onerror` invocation now sets `this.#workerBroken = true` unconditionally (regardless of current state). The existing `#fail('worker-not-ready')` path that the pre-ready branch already uses is the natural failure surface for a later `submitFiles()` — but the busy floor is the actual hang surface. The submitFiles() guard must therefore run BEFORE any `postMessage` call and BEFORE the busy floor timer starts.

Why this is one-line and not a redesign: PLATFORM-02 forbids any post-load script fetch, so respawning the worker is structurally not an option. The single-worker rule (`src/lib/worker/db.ts` depends on exactly one Worker for the page lifetime) means the dead worker stays dead; a broken flag is the only response. The 04-07 `playtime.failPending()` release on the same `onerror` event is unchanged — the new code only adds the broken flag, it does not remove the playtime release.

Purpose: closing WR-01 removes the only advisory that can leave the user staring at a spinner that never resolves. With this plan, a worker that errors between submissions leaves the user with the same "worker not ready" failure banner they'd see if the worker had died before the page was usable — visible, dismissible via Start Over, no infinite spinner.

Output: hardened `src/lib/worker-client.svelte.ts` and one new test in `tests/unit/ingest-client.test.ts`.

Cross-references:
- WR-01 fix site: `src/lib/worker-client.svelte.ts:181-203` (the `onerror` handler).
- Existing pre-ready broken-worker path: same lines, the `else if (!this.workerReady)` branch (lines 193-200) — the pattern the new code extends.
- Existing `submitFiles` busy + broken guard: `src/lib/worker-client.svelte.ts:384-403` — the guard the new flag must compose with.
