<objective>
Add the Virtual currency sub-block to the Financial_data card: one diverging monthly chart per charted currency with its own scale, the text rows for every other currency, the excluded-operation pill and the monthly data tables, reusing the chart component and tooltip built for the premium timeline.

Purpose: FINANCE-02 asks for a timeline of virtual-currency flow with income and spending over time. The data side (exact sums, the 50-operation threshold, the cap of 8, the other-currencies list) is plan 05-04; the chart, grid semantics and tooltip are plan 05-11; this plan composes them per currency and proves the scale cases (a 20-year history, many currencies, none above the threshold) in a browser.

## Planner assumptions and flags

- **Container versus SVG test id.** UI-SPEC section 5 gives test id `currency-chart` (with data-currency) to the chart BLOCK; the SVG therefore takes `currency-svg` through the chart component's `chartTestId` prop, so the premium and currency charts keep one component.
- **Data attributes carry numbers.** `data-in` and `data-out` are the plain numbers of whole currency units (`unitsToNumber`), exact for integers; sums in tests are compared with the oracle's integer totals. `data-currency` carries the code as written (UI-SPEC section 15) and is never concatenated into a selector.
- **Zero line label.** The 0 label at the zero line is the fixed character; only the top and bottom labels depend on the data.
- **Task 3 may touch MonthlyBarChart.svelte** only to fix a defect the 240-month and clipping tests expose; plan 05-11 owns the component and its Phase 4-style contract test.
- **No new copy.** Every string is an export of ui-copy.ts from plan 05-08.
