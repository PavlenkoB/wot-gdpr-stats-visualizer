## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| main thread to worker (`playtime-query.game`) | a postMessage field the worker did not author; any string, number or object can arrive |
| zip file name to game token | the token is untrusted text from an archive file name, then stored in IndexedDB and echoed to the UI |
| stored aggregate to main thread | derived, PII-free scopes cross; no row cell, no IP |
