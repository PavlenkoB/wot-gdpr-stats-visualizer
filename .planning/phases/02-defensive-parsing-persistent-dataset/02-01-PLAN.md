<objective>
Turn the Phase 1 path-only worker into a defensive CSV-parsing, mojibake-correcting, IndexedDB-persisting pipeline. Every detected category folder — supported, known-deferred, and unknown alike (D-01) — gets fully unzipped and parsed inside the ingest worker, with mojibake fields corrected and the result written to a single active Dexie dataset in one transaction. A hash computed from the raw zip bytes, before any unzip work, detects an identical re-upload and skips it (IMPORT-06 mechanism).

Purpose: This is the phase's foundational vertical slice — without it, nothing else in Phase 2 (return-visit auto-load, skip-count display, destructive-action UX) has anything to build on.
Output: New worker-local modules (hash.ts, mojibake.ts, csv-parse.ts, db.ts), an extended worker message contract, an extended ingest worker, row counts visible on every category badge, and a fully working import → parse → persist path proven end to end.
</objective>
