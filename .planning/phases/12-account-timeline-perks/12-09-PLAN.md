<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker answer (cells from an untrusted export) to the DOM | text only, through formatNewDataCell; nothing may reach an attribute |
| the shell's single reveal to the pane | the pane must not hold its own reveal state |
| one dataset's answer to the next dataset's screen | a late reply must not paint under a new heading |

## STRIDE Threat Register

Threat IDs are unique within the phase; this plan owns T-12-28 to T-12-30.

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-12-28 | Information disclosure | a coupon code, a bonus code or the bonus-code user IP appearing in the DOM, an attribute, a title, an aria-label, a test id, document.title or a log while masked | high | mitigate | Cells reach the DOM only through formatNewDataCell (code and address kinds masked unless revealed); the source-shape guard forbids title and aria-label attributes and any cell-bearing attribute; the pane adds no state, so a new dataset re-masks by the shell's stamp; plan 12-13 scans markup for the planted code and address until the reveal. |
| T-12-29 | Information disclosure | the worker's error detail (which may name internals) shown in the pane | low | mitigate | The error branch renders the fixed PERKS_ERROR sentence only; the guard asserts the constant is the only text in the alert. |
| T-12-30 | Spoofing | a late or superseded perks answer painted under a newly imported dataset's heading | medium | mitigate | The applied answer is stamped with the dataset it answers for and acceptDataOutcome drops a reply whose importedAt differs; the state falls back to loading by construction. |
| T-12-SC | Tampering | npm/pip/cargo installs | high | mitigate | This plan installs no package. Any future install needs a RESEARCH.md Package Legitimacy Audit and a blocking human checkpoint for [ASSUMED]/[SUS] entries. |
