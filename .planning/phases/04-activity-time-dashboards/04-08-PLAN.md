## Planner assumptions and flags

- **Idle status line.** The UI-SPEC says an empty live region adds no height. In a flex column with a 24px gap an empty paragraph would still take a gap slot, so the empty status line is visually hidden with the 1px clip pattern `Dropzone.svelte` uses (it stays in the accessibility tree, so announcements still work) and returns to normal flow when it has text.
- **Split table when the selection is beyond the eighth value.** No row carries the current-selection marker (see plan 04-05); the select shows it.
- **Component verification.** Vitest has no DOM, so the components are verified by `pnpm run check`, lint, build and by the Playwright specs in plan 04-11, which run in CI (Chromium cannot be downloaded in the cloud sandbox). The logic they depend on is unit tested in `playtime-state.ts` and `playtime-model.ts`.
