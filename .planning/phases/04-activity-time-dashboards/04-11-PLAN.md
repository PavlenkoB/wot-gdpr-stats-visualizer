## Planner assumptions and flags

- **Chromium.** It cannot be downloaded in the cloud sandbox, so every browser assertion is verified by `playwright test --list` here and by a CI or developer run. The human-check blocks in each task name that run.
- **Delayed queries.** Loading and updating are only observable if the worker's answer is late, so an init script wraps the worker's postMessage and delays playtime-query messages; no network is involved and the zero-network guard is unaffected.
- **Error state.** The error state is reached by corrupting the cache directly through the raw indexedDB API (database name wg-export-viewer, the pattern identity-privacy.spec.ts uses to read it): clear the stored playtime aggregate and null the data of the Sessions rows, then reload, so the lazy backfill throws and the block shows its own error message while the dataset stays on screen.
- **Hour cell expectations (pending user decision, UI-SPEC unresolved row).** The fixture module holds both bases as complete hand-derived tables (see Artifacts): under the start basis six cells differ from the overlap basis (Monday 20:00 and 21:00, Friday 12:00 and 13:00, Saturday 23:00 and Sunday 00:00), not only the two Saturday and Sunday cells, and the tooltip second line of cell 20 differs too. The spec reads the table through `expectedHourSeconds()` and `HOUR_CELL_20_LINE2[HOUR_GRID_BASIS]`, both keyed by the same `HOUR_GRID_BASIS` constant the app reads, so the user's decision needs no spec edit; the unit cross-check verifies both tables in the sandbox whichever basis is active.
- **Test budget (CI).** CI runs one Playwright worker with a global timeout, so every test added here is paid for in the pipeline. This plan therefore caps the two spec files at 36 tests in total (planned: 1 tracer, 18 in playtime.spec.ts Task 2, 16 in playtime-charts.spec.ts) and every test imports the nine-row fixture, never a large one. Plan 04-13 reads the recorded `--list` totals and checks the derived timeouts; exceeding 36 tests requires amending plan 04-13's estimate in the same change.
