Decisions implemented here: none new; D-13 and D-17 are honoured exactly as written (the id-only row still leads its row with the account root, and nothing about the ID is removed). The UI-SPEC amendment follows the W-03 precedent from Phase 4: when the code and the contract disagree, the contract is amended in the same commit and the reason is recorded.
