# Sketch 021: Q2 Configurator

## How to View
open .planning/sketches/021-q2-configurator/index.html

## Options (dark bar at top; j/k move between sections)
- **Theme**: Light (from 008/012), Dark (from 011 Q2a), Swiss (from 017 Q2h)
- **List**: Rows (compact), Preview cards (Q2b / 012), Big type (Q2h)
- **Properties panel**: Off / On (Q2e)
- **KPI chips**: Off / On (Q2d)
- **Rhythm chart**: Heatmap / Polar clock (R1, 012)
- **Prev/Next**: On / Off (Q2b)

The green line in the bar shows the current combination.

## Decision
Chosen combination: **Light + Rows + Properties off + KPI chips off + Heatmap + Prev/Next off**.
This is the minimal Q2: compact list of sections (title, headline value, one-line summary) on the left, one section's detail on the right, j/k keyboard navigation. Preview cards, polar clock, properties panel, chips and Prev/Next were tried and deliberately not chosen; they remain available in sketches 011, 012, 014, 017 and 021 if revisited.
