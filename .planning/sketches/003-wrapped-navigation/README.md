# Sketch 003: Wrapped Navigation

## How to View
open .planning/sketches/003-wrapped-navigation/index.html

## Variants
- **G: Dot rail** - left dots expand to labels on hover, top progress bar, arrow keys
- **H: Story segments** - Instagram-style segmented progress at top (click to jump), chapter title, prev/next buttons
- **I: Dock + overview** - bottom icon dock (phone-friendly) plus an Overview grid of chapter cards

## What to Look For
Always-visible vs hover discovery, phone usability, keyboard flow, does it still feel like a story.
