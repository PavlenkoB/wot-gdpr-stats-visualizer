# Sketch Manifest

## Design Direction
**FINAL (2026-10-07): Q2 master-detail, minimal.** Light theme, compact rows list (title, headline value, one-line summary), single detail pane, standard heatmaps, no properties panel / KPI chips / Prev-Next / polar clock. j/k keyboard nav. See sketch 021.

Earlier exploration: Current dashboard looks default/ugly (narrow column, flat gray boxes, raw folder-name headings, no hierarchy). User wants all three directions compared: dark game-stats HUD, clean modern light, warm editorial.

## Reference Points
WoT stats sites / Grafana (A), Linear / Vercel (B), Spotify Wrapped / NYT charts (C).
