# Sketch 001: Dashboard Look

## Design Question
Current UI: 720px column, unstyled controls, raw folder names as headings, identical gray boxes. Which direction fixes that?

## How to View
open .planning/sketches/001-dashboard-look/index.html

## Variants
- **A: Dark HUD** — dark theme, left sidebar nav, 2-col card grid, teal glow ramp
- **B: Clean Light** — light, sticky top pill nav, wide card grid, soft shadows
- **C: Editorial** — warm paper, serif headings, big numerals, ruled sections instead of cards

## What to Look For
Hierarchy (what you see first), density, heatmap legibility, how the long login table and wall-of-text notes are tamed, phone width (toolbar buttons).
