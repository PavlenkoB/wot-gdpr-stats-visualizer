# Sketch 027: Fresh alternatives B

## How to View
`node .planning/sketches/_shared/gen-data.mjs` once, then open `.planning/sketches/027-overview-fresh-b/index.html`.

## Variants
- **J: Ask your data** - search box + eight suggested questions; each answers with one big number, a sentence, a small chart and the rule. Deterministic rules (no AI, nothing sent), empty state when nothing matches.
- **L: Milestones timeline** - dated facts only, in order: first session, longest session, biggest year, busiest day, quiet 2019-2021, 52-day streak, second account folder starts, latest session. No invented dates.
- **I: Sticky-visual chapters** - five chapters; on wide screens a chart on the left follows the chapter in view (IntersectionObserver), on narrow screens each chapter carries its own chart. Content never hidden behind scrolling; reduced motion respected.

## What to Look For
- J: does asking beat browsing for this audience, or is it a gimmick? What if the question list is wrong for another game?
- L: does a timeline tell the 14-year story best, given it only has session-derived dates?
- I: is the sticky visual worth the complexity over plain chapters (sketch 022-A)?
