## Planner assumptions and flags

- **Cells carry their own kind.** A discriminated cell (`t`) keeps the main thread from guessing what a number means; the model (plan 05-09) sorts on it and the table (plan 05-12) formats it.
- **Accepted-spelling fallbacks.** Each field lists the UI-SPEC header first and the other titles' spellings of the same field after it, so a newer export that renames within the family still maps. Fallbacks are an input-tolerance choice, not a promise that any header name is stable (RESEARCH A8).
- **Blank vehicle name.** A row with a blank VEHICLE_NAME keeps id as an empty string and no nation; the table plan renders the fixed fallback copy for it.
- **Row order.** The builder preserves file order; sorting is the main thread's (plan 05-09), so the builder never decides what the user sees first.
- **Vehicle ids outside WoT.** The split on the first colon is generic (RESEARCH A9); only WoT ids are verified to carry a prefix.
