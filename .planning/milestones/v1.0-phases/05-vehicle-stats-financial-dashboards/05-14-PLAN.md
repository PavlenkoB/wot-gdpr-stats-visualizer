## Planner assumptions and flags

- **Summary versus select.** The summary lists all codes of the Battle_Types file and the select only the by_Type codes, so on the fixture the codes 11 and 13 appear in the summary and not in the select; this is expected (RESEARCH Pitfall 10) and a test asserts it.
- **Picked extras are validated against the view.** The picked list is held in pick order; the checkboxes and the visible columns come from the extras the CURRENT view offers, so a key left over from a previous view is neither shown nor counted.
- **Warships All-view columns.** Last battle and In garage are core columns there, so they are not picker items; the picker's only extra is Distance.
- **No new copy.** Every string is an export of ui-copy.ts from plan 05-08.
- **Header drift test.** A WoT file without its XP column is built with a buildCustomExport override that removes the header and cells of that column; the expectation is the not in export special in every cell of the Total XP column, never 0.
- **Task 3 files are the same two components plus the spec**; fixes are conditional on what the 375px checks expose.
