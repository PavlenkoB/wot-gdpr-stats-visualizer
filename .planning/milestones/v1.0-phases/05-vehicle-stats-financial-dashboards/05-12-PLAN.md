## Planner assumptions and flags

- **Task 1 touches eight files**; four are one-line or list edits (Dashboard branch, status flip, status test, dashboard spec) that must land with the block so the unit and Phase 3 browser suites are never red between commits.
- **Reconciling an unapplied ask.** Like Phase 4's reconcile of a dropped answer, once an answer is applied the block rewrites `requested` to what the view actually applied, so a battle type the worker declined (or a title it defaulted) cannot leave the status line on Updating table forever.

- **Live region.** A polite, atomic status paragraph exists in every state; the Financial and spend blocks use role only, so the count is three.
- **Hints and notes.** Only the count line, the derived-value note, the two hints and the title state lines are in this plan; the battle-type note, the Warships all-battles note and the Warplanes 20 note are plan 05-14's.
