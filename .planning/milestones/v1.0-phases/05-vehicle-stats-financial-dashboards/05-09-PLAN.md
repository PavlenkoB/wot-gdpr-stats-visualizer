## Planner assumptions and flags

- **Why this plan waits for plan 05-08.** The models are independent of it; the dependency exists only because plan 05-08 adds the pin-locale import to tests/e2e/scroll-nav.spec.ts and this plan edits the same file, so the two cannot share a wave.
- **Hidden nav scrollbar (planner decision, flagged).** UI-SPEC section 1 says the nav scrolls inside its own container but is silent on the scrollbar. RESEARCH Pitfall 12 recommends hiding it so the nav's auto height cannot change by scrollbar thickness on platforms with classic scrollbars (headless Chromium hides them, so CI cannot see the difference). The current link is kept visible by the nav's own scroll position, and links stay keyboard-reachable.
- **Model inputs are plain numbers.** The caller converts micro-unit strings with the decimal module's number helper; the model never sees BigInt, so it stays trivially testable.
- **Bar heights are rounded to whole pixels** with a 2px floor for non-zero months; the exact value is always available from the tooltip, the cell name and the monthly table.
- **Currency axis labels** (the y-axis compact values) are formatted by the component with the compact formatter; the model supplies only the domain maximum.
- **Date extras sort by wall-clock seconds** carried in the cell (null sorts as special), never by the text.
