<objective>
Generate the world map as committed, static, per-country SVG path data at build time, so the runtime map is a plain list of paths with no mapping library in the shipped bundle.

Purpose: ACTIVITY-06 asks for country shading on a bundled world-map SVG. AGENTS.md fixes the method: `world-atlas`, `d3-geo` and `topojson-client` run only in a Node build script; the shipped module is pre-rendered paths. This plan produces that module and the proof that it is deterministic and dependency-free at runtime.

Tracer note: Task 1 is the slice: the three packages and the script produce a module from the 110m data, and a test reads one country's path from it. The hybrid, the special cases and the reproducibility check follow in Task 2.

Output: three build-time devDependencies, `build-world-map.ts`, `world-map.generated.ts` and its tests.
</objective>

Per D-09 (aggregate per country, so the map is a list of country shapes) and the AGENTS.md rule that geo tooling is build-time only, install the three approved packages as exact-version devDependencies with `pnpm add -D world-atlas@2.0.2 d3-geo@3.1.1 topojson-client@3.1.0` (verdict OK in the legitimacy audit, no postinstall; commit `pnpm-lock.yaml`). `scripts/geo/build-world-map.ts` (a Node file, explicit `.ts` imports for local modules, no enum or namespace): load the 110m countries file of `world-atlas` through `createRequire`, convert with the topology-to-GeoJSON function of `topojson-client`, derive each feature's alpha-2 code with `Intl.getCanonicalLocales('und-' + id)` (split on the hyphen, take the second part; no table), project with a Natural Earth projection fitted to a 960 by 500 sphere, and render each path with one digit of precision. Emit `world-map.generated.ts` with a header comment marking it generated (source package versions, projection, no hand edits) and exporting `WORLD_VIEWBOX` as `0 0 960 500`, the `WorldShape` interface (iso, d, cx, cy, tiny) and `WORLD_SHAPES` sorted by iso for determinism. The centroid comes from the path generator's centroid rounded to one decimal; `tiny` is true when the projected bounding-box area is under 12 square pixels. Add package scripts `geo:map` (`node scripts/geo/build-world-map.ts`) and `geo:map:check` (the same with `--check`). Only the script ever imports the three packages.

Run `pnpm run geo:map` and commit the output. `tests/unit/geo/world-map.test.ts`: import the module and assert that `DE` is present with a non-empty `d` beginning with `M`, that every iso is two upper-case letters and unique, and that `WORLD_VIEWBOX` is `0 0 960 500`.
