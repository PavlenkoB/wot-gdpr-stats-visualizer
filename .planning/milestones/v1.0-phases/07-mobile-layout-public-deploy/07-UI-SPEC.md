## Mobile & Touch Interactions

### Spacing & Layout (D-03)

At phone width (viewport ≤ 480px):
- Page padding shrinks from desktop `24px` to 16px.
- All child elements (sections, cards, tables, maps) reflow to fit the narrower safe area with no horizontal page scroll.
- Wide content (vehicle table, login table, charts) retains its own internal scroll box (D-01, D-02).
- The sticky nav remains in place; its height and offset contract (`--nav-offset: 72px`) are unchanged.

No hidden columns, no card reflow, no summary/tabbed view.

### Touch Targets (D-08)

All buttons, links, and sortable headers must meet a **minimum 44px bounding-box hit area** (width and height) at phone width and `coarse` pointer input.

**Elements affected:**
- Nav anchor links
- Reveal-IP toggle button
- City opt-in Load / Cancel buttons
- IP table sort header buttons
- Country list / city list summary buttons
- Clear cached data button
- Confirm panel buttons (from Phase 2, inherited)
- DB-IP attribution link
- Focus ring on map countries (roving focus per Phase 6)

**Elements exempt:**
- Chart marks (heatmap cells, map countries): tap-to-pin (D-05) handles precision; hit circles are acceptable at smaller sizes.
- Native `<progress>` bar: not interactive.
- Text selection inside table cells and non-interactive text.

### Touch Tooltip Interaction (D-05, ChartTooltip)

The shared `ChartTooltip` component (Phases 4–6) is reused by CalendarHeatmap, HourGrid, MonthlyBarChart, and WorldMap. **New touch behaviour:**

| Pointer Type | Trigger | Tooltip State | Dismiss |
|--------------|---------|---------------|---------|
| Mouse | Hover | Open (auto-close on leave) | Mouse leave, Esc |
| Touch / Coarse | Tap | **Pinned** (persists across touches) | Tap outside, scroll, Esc, or tap the cell again |

**Pinned state behaviour:**
- Tapping a chart mark opens the tooltip and pins it (tooltip stays visible).
- Tapping another mark moves the pinned tooltip to the new mark.
- Tapping anywhere outside the tooltip closes it.
- Scrolling the page dismisses the tooltip (silently).
- Pressing Esc dismisses the tooltip without moving focus.
- A live region announces: `Tooltip pinned.` (on first tap to pin) / `Tooltip dismissed.` (on tap outside or Esc only, not on scroll).

**No timers, no auto-dismiss.** Touch tooltips persist until explicitly closed, giving mobile users time to read.

**Keyboard navigation unchanged:** Arrow keys move between chart items; Enter activates if applicable.

### Table Scrolling (D-01)

Vehicle table, Login IP table, and secondary tables (Country list, City list) keep their own `overflow: auto` containers with sticky headers and, where applicable, sticky first columns.

**No horizontal page scroll.** Tables scroll inside their own bounded box.

**No vertical reflow to cards, no column hiding.** The six IP table columns remain in place; Phase 7 is width/padding tuning and touch polish, not restructuring.

**Optional visual hint (planner discretion):** An edge-fade or scroll indicator on table edges may be added to hint that more content exists; this is not a contract requirement.

### Map Scaling (D-02)

The World map SVG (`viewBox="0 0 960 500"`, rendered `width: 100%; height: auto`):
- At desktop width: 638px card ÷ 960 viewBox = 0.664× scale, ~332px tall.
- At 375px phone: 343px card ÷ 960 viewBox = 0.357× scale, ~179px tall.
- **No pinch-zoom or pan controls.** The map scales only; it never requires interaction beyond keyboard roving focus and tap-to-pin (D-05).
- Per-country figures are in the ranked country list below; the summary sentence and tooltip provide context (Phase 6 D-10).

## UI Considerations

### Focal Point at 375×812 Viewport

The **Phase 6 focal point** (Phase 6 Section 12) remains above the fold at phone width: the identity header, nav, summary count tiles (Login count, IP count), the begin of the login table or heatmap, and the map are all within the initial viewport. Detailed country/city lists and the chart's fine detail are below, as secondary content reachable by scroll (D-02, D-04).

### Responsive Layout at Phone Width

**Responsive at phone width:**

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| No horizontal scroll | Identity header, nav, heatmaps, tiles, tables, map, banners, controls | ✅ covered | `main { max-width: 720px; padding: 16px }` ensures `document.scrollWidth ≤ clientWidth` (confirmed by D-04 mobile proof e2e spec) |
| Touch targets | All buttons, links, sort headers, summary toggles | ✅ covered | Minimum 44px bounding box at coarse pointer (D-08, verified by bounding-box assertion per D-04 note) |
| Wide table columns | Vehicle table (6 cols, 720px), Login table (6–7 cols, 720px) | ✅ covered | Scroller `overflow-x: auto; max-width: 100%` keeps table inside its container; sticky first column keeps identity; Phase 7 is polish, not restructuring (D-01) |
| Chart readability | Calendar heatmap, hour grid, monthly bar chart, world map | ✅ covered | SVG `width: 100%; height: auto` scales to fit container; no text inside; map shrinks to 179px tall at 375px (D-02); tooltip pinned on tap (D-05) |
| Long text | Account names, country names, city names, IP addresses | ✅ covered | `overflow-wrap: anywhere` on cells holding untrusted data; IP cells wrap to max 2 lines at 40px row height (Phase 6 D-05, verified at 375px) |
| Form labels | Input buttons, toggles, checkboxes, select options | ✅ covered | All are Label or Body role; no smaller than 14px; focus ring is 3px accent (D-08) |

## Deltas from Phase 6 (for the checker)

1. **New `@media (max-width: 480px)` block:** Page padding shrinks from `24px` to 16px.
2. **Touch tooltip interaction:** `ChartTooltip` instances (map, heatmaps, bar chart) gain tap-to-pin, move-on-tap, and pinned-dismiss states with live-region announcements.
3. **44px touch target rule:** All buttons, links, and interactive headers meet a minimum hit area at phone width / coarse pointer input.
4. **Map scaling:** SVG `viewBox` remains fixed; scaling is `width: 100%; height: auto`, which is allowed because the SVG contains no text.
5. **No new dependencies:** Touch interaction is achieved via `pointerType` check in existing pointer event handlers; no new libraries.
6. **E2E scope expansion:** D-04 introduces a sweep spec at 375×812px and a second Playwright project with `hasTouch: true` / `isMobile: true` (Chromium emulation).
7. **No deprecated or retired elements:** Phases 2–6 copy, components, and chrome are preserved exactly; Phase 7 only adds mobile layout and touch polish.
