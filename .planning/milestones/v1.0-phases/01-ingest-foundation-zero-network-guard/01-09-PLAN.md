<objective>
Close five advisory code-review findings against the build/CI configuration:

1. **WR-02 (architectural):** `vite.config.ts` registers two plugins (`cspMeta` and `unescapeQuotes`) in a specific order. Reordering would silently ship `&#39;` HTML escapes in `dist/index.html`. Fold the unescape step into `cspMeta` so there is no order dependency.
2. **WR-04 (efficiency):** `pnpm run check` runs two `svelte-check` passes plus one `tsc -p`, tripling CI typecheck overhead. Replace with a single `tsc -b` invocation driven by the existing top-level `tsconfig.json` (which already project-references `tsconfig.app.json` and `tsconfig.node.json` and is missing the `tsconfig.test.json` entry).
3. **IN-01 (consistency):** `tsconfig.app.json` is missing `verbatimModuleSyntax: true`, while `tsconfig.node.json` and `tsconfig.test.json` already have it. Add it.
4. **IN-02 (config):** `tsconfig.app.json` has `checkJs: true` with no JS files in `src/`. The flag is a no-op and a future contributor adding a `.js` file would silently get type-checked JS. Remove it. (Keep `allowJs: true` — `.svelte` files embed JS and the svelte-check pipeline depends on it.)
5. **IN-05 (config):** `svelte.config.js` is `export default {};` with no comment. Either annotate it or delete it.

**WR-05 deferred.** The advisory recorded that the Playwright `webServer` teardown hangs via the `pnpm -> node` signal chain, and the fix was "use direct binary invocation". On inspection during planning, `playwright.config.ts` already runs `./node_modules/.bin/vite build && ./node_modules/.bin/vite preview` (direct binary, no pnpm wrapper) and `tests/unit/webserver-teardown.test.ts` exists as the regression guard for that exact bug. The fix is in code; only the SKILL.md and `01-VERIFICATION.md` advisory block still describe it as an open item, and that is a doc drift (planned for Plan 01-10). WR-05 is therefore closed in code and NOT in this plan's gap_ids list. This plan records the verification rather than re-doing the fix.

**Single-file `src/lib/worker/ingest.worker.ts` note.** The `cspMeta` plugin's HTML-entity unescape was originally needed because the CSP string contains `'self'` and `'none'` — quoted phrases that some upstream transformer once double-escaped to `&#39;self&#39;` and `&#39;none&#39;`. The fix folds the unescape into the same plugin that does the injection, so the order no longer matters and a future plugin between them cannot break the output. This plan reads `src/lib/worker/ingest.worker.ts` once (Task 1, declaration read) to confirm there is no other place in the build pipeline that emits HTML-escaped quotes that the folded unescape needs to handle; the worker file itself is not modified.

Output: hardened `vite.config.ts` (one plugin instead of two), `package.json` (one typecheck command), the top-level `tsconfig.json` (adds the missing `tsconfig.test.json` reference), `tsconfig.app.json` (one flag added, one removed), and either deletion or annotation of `svelte.config.js`.
