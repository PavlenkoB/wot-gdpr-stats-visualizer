<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Sessions.csv value cells to split values | SERVER_NAME and CLIENT_PLATFORM cells are attacker-controlled strings that become labels and Map keys |
| Stored meta to a later query | The stored aggregate is trusted only when its version matches; otherwise it is rebuilt from rows |
| Concurrent replace to a backfill write | A slow backfill must not attach the previous dataset's aggregate to a newer dataset |
