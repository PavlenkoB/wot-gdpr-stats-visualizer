## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker result to main-thread pure functions | Category names (zip folder names) are untrusted strings that these functions compare and return but never interpret |
| copy formatters to the rendering layer | Formatters return untrusted text unchanged; escaping is the Svelte text-interpolation layer's job |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-07 | Tampering | Untrusted folder names and account root flowing through formatters | high | mitigate | Formatters do plain string concatenation only and never produce markup; a unit test pins that markup characters stay literal; the rendering plans use text interpolation only and rely on the existing svelte/no-at-html-tags lint error |
| T-03-08 | Denial of service | Regular expressions on untrusted strings (`/[ T]/` split, number parse) | low | accept | Single-character class and a bounded parse; no nested quantifiers; input length is one CSV cell |
| T-03-09 | Repudiation | Absent versus empty conflated, misleading the user about what the export contains | medium | mitigate | Distinct statuses and distinct wording (D-10) locked by unit tests and the plan prohibition |
| T-03-SC | Tampering | Package installs (npm/pip/cargo) | high | mitigate | No package-manager install in this plan; `git diff --quiet 9558a26 -- package.json pnpm-lock.yaml` must exit 0 |
