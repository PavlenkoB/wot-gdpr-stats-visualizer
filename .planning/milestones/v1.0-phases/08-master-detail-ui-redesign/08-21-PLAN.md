|----------|-------------|
| browser layout to heatmap model | a measured pixel width, set by the user's window, becomes input to geometry arithmetic |
| export CSV to calendar | session dates from an untrusted zip decide which years are drawn (every day of each, up to the date window) |
| heatmap to network | nothing here may add a request; the measuring is a local DOM read |

## STRIDE Threat Register

Threat IDs continue after plan 08-20's register (highest T-08-54); T-08-SC is reserved and kept.

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-08-55 | Denial of service | calendar model rebuilt when the measured width changes (366 cells per active year, up to a decade or more) | low | mitigate | The width is floored to an integer and passed to the model only when it changes, a ResizeObserver delivers at most once per frame, the cell count stays a function of the active years (the Phase 4 node-count rule) and never of the width or the session count, and `tests/e2e/playtime/playtime-scale.spec.ts` stays green; a wider pane makes bigger cells, not more of them |

| T-08-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package is installed or changed; `package.json` and `pnpm-lock.yaml` stay byte-identical (checked in plan 08-22), so the package-legitimacy gate has nothing to audit |
