Verified facts:
- Chart Escape handlers do NOT call preventDefault (CalendarHeatmap, HourGrid and WorldMap call `onTip(null, null)` and return; ChartTooltip's document-level capture handler dismisses a pinned tooltip and also does not call it). A `defaultPrevented` check alone therefore cannot protect a chart; the detail-pane handler must also bail when the event target is inside an element carrying `data-tooltip-surface` (HourGrid scroller, CalendarHeatmap root, WorldMap, MonthlyBarChart scroller all carry it).
- `ImportBar`, the confirm panel and the dropzone live in the list pane below the nav, so the key handler is scoped to the `<nav>` element, not to the whole pane.
- Buttons activate on Enter by firing click on keydown; calling `preventDefault()` on the keydown suppresses that click.
- The global 44px touch floor lives in the single 480px block of app.css and already applies to `button`.
- The existing phone-width media block in a component may be used (precedent: DurationList, App.svelte) because a scoped rule outranks a global one; it must use the same 480px width as PHONE_MAX_WIDTH_PX.
- Use Svelte 5 event attributes (`onkeydown`), `$state`, `$derived`, `onMount`; no `<slot>`, no `on:` directives.
