| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-12-31 | Tampering | the cross-account merge collapsing two rows that differ in some allowlisted column, or merging files D-10 does not name | medium | mitigate | The merge key covers every column of the spec, absence differs from an empty string, a same-account repeat is never merged, only Subscriptions is merged; the pure builder tests include a one-column difference, a same-account repeat and the unmerged coupon case. |
| T-12-32 | Information disclosure | a legacy stored row with an unnarrowed raw column (an email, a profile id) reaching a posted view before the in-place narrowing has run | high | mitigate | The builder reads only spec column ids and never walks a row's keys; the worker test seeds a legacy row with an extra raw column and asserts its value appears nowhere in the view. |
