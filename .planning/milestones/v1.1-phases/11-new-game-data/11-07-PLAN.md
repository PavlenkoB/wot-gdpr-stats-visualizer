## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored rows to the posted view | a view crosses `postMessage` to the page; only spec cells and counts may |
| page to worker query | a `postMessage` field the worker did not author |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-11-21 | Information disclosure | a builder reading a non-allowlisted key from a legacy or hand-seeded row into a view | high | mitigate | Cells are read by direct access through the spec's constant headers; the builder never iterates a row's keys (grep-gated); tests seed a canary into a stored row and into a view input and search the serialised view. |
| T-11-22 | Tampering | a smuggled field on a heat or warships-storage query | low | mitigate | The channels join the field-less group in `isDataQuery`, which rejects any extra field with a fixed detail; a worker test asserts it. |
