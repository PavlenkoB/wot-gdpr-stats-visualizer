| T-11-SC | Tampering | npm/pip/cargo installs | high | mitigate | This plan installs and upgrades no package. Any future install needs a RESEARCH.md Package Legitimacy Audit and a blocking human checkpoint for [ASSUMED]/[SUS] entries. |
