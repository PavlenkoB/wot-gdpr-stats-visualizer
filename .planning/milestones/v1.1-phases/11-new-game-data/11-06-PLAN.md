## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| reveal state to every pane that shows an address | a reveal that outlives its dataset, or starts true, discloses addresses of a dataset the reader has not chosen to reveal |
| remembered Vehicles title to the worker query | the title travels as a query field; the worker already validates it against the four title ids |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
