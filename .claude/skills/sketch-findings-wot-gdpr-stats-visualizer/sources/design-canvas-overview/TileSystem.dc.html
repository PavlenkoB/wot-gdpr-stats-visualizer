Columns follow the width of the content area, not the window: 4 from 880 px, 2 from 480 to 879 px, 1 below 480 px. Importance order, not desktop position, decides the stacking order. A group never ends on a part-empty row: the last tiles widen to fill it.

Chrome stays neutral ink. Colour on tiles is limited to a group dot beside headings and labels and an amber star on pinned tiles; tiles are white and numbers are ink. Value charts (years, hours, top 5) are coloured by value, see the scale below; categorical charts (the class split) keep the teal ramp. #8c8c8c is decoration and dashed borders, never text.

Chart value scale
lowvalue relative to the chart's peakpeak

Light green #4fb27f, olive #6b8a14, dark gold #8c6400, eased so most bars stay green and only the highest turn gold. Lightness falls as the value rises, so the peak is still the darkest bar in greyscale and for colour-blind users. Fills measure 2.6 : 1, 4.0 : 1 and 5.3 : 1 against white; the peak is also named in text above the bar and the bar length carries the value, which meets WCAG 1.4.11 for graphics that repeat text. A small low-to-peak legend sits in the heading of every group that contains a chart. Grafana's bright yellow (#f2cc0c, 1.5 : 1) would make the peak the faintest bar.

Behaviour
  • Opening grows the tile downward in its own column; it never moves sideways or changes width.
  • Siblings keep their natural height while a tile is open.
  • Changes animate for 260 ms and are skipped under reduced motion; scroll is anchored to the changed tile.
  • Esc closes and returns focus to the tile; arrow keys move between tiles.
  • Absent data is a dashed tile saying so, never a zero.
